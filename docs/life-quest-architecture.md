# 🎮 LifeQuest — Архитектура веб-приложения геймификации жизни

---

## 1. Анализ предоставленных материалов

### Что представляет собой исходная система

По 8 скриншотам восстановлена следующая картина: это **персональная Obsidian-система** пользователя Амира, которая превращает повседневную жизнь в RPG-игру с уровнями, очками опыта и прогрессией навыков.

### Восстановленные модули

| Модуль | Что видно на скриншотах | Предполагаемая логика |
|--------|------------------------|----------------------|
| **Профиль-персонаж** | Level 10, 101/180 XP, аватар, 5 сфер (Интеллект, Дело, Энергия, Порядок, Связи) | Общий уровень растёт от суммарного XP. Каждая сфера — отдельная ветка прокачки |
| **Сферы жизни** | Радарная диаграмма, у каждой сферы свой Lv (0–9) и прогресс-бар (например, Дело Lv.9 — 24/120) | Уровень сферы повышается при накоплении XP в связанных активностях |
| **Активности** | Карточки: Кодинг (LVL 8), Сон (LVL 6), Видеомонтаж (LVL 4) и др. Счётчик X/365, время | Каждая активность — «навык», который прокачивается логированием. 365 — годовой трекер |
| **Здоровье** | Трансформация тела (99→95→75 кг), календари шагов и ккал, коридоры калорий (дефицит/норма) | Модуль отслеживания физической формы с гибкими настройками |
| **Ежедневник** | Дневные квесты, пульс дня, вес, финансы, питание, активности, чтение, тренировки, заметки | Ежедневная страница — центральный хаб для ввода данных |
| **База продуктов** | Продукты на 100 г с КБЖУ, категории (крупы, готовые блюда, макароны) | Справочник для подсчёта питания |
| **Цели** | «На автомобиль» — 2150/10000$, 22% | Долгосрочные цели с финансовым трекером |
| **Казна и арсенал** | Медали (золото ×3, серебро ×2), монеты (16) | Награды за достижения, внутренняя валюта |
| **Магазин наград** | «Вкусный Снек» — любимая награда | Можно «покупать» награды за накопленные монеты |
| **Итоги** | Месячная сводка: XP, задачи, тренировки, сон, ккал, чтение | Аналитика за период |
| **Навигация** | Главная, ToDo, FAQ, Картотека (Фильмы, Сериалы, Игры, Библиотека, CRM) | Структура знаний и развлечений |

### Что НЕ видно, но логически необходимо

- **Система начисления XP** — формулы, за что именно даётся опыт
- **Механика уровней** — пороги перехода, прогрессивная сложность
- **Квесты** — типы, сроки, привязка к наградам
- **Стрики (серии)** — поддержание привычек
- **Социальная механика** — система работает для одного пользователя
- **Система достижений** — ачивки за вехи прогресса

## 2. Улучшенная модель геймификации

### 2.1 Система опыта (XP)

Представь, что каждое полезное действие в жизни — это монстр в RPG. Убил монстра → получил опыт. Только вместо монстров — задачи, привычки и активности.

**Источники XP:**

| Действие | Базовый XP | Множитель |
|----------|-----------|-----------|
| Выполнение ежедневной задачи | 10–30 | ×1.5 за стрик 7+ дней |
| Завершение привычки | 5–15 | ×2 за стрик 30+ дней |
| Логирование активности (за час) | 15–25 | ×1.2 за регулярность |
| Завершение квеста | 50–200 | Зависит от сложности |
| Достижение цели (milestone) | 100–500 | Единоразовый бонус |
| Тренировка | 20–40 | ×1.3 за серию |

**Множители и бонусы:**
- **Стрик-множитель**: чем дольше серия без пропусков, тем больше XP (как комбо в файтинге)
- **Бонус фокуса**: +20% XP, если активность в текущей «фокус-сфере»
- **Утренний бонус**: +10% за задачи до 10:00 (приучает к продуктивному утру)

### 2.2 Система уровней

Пороги уровней растут логарифмически — как в играх, где первые уровни быстрые, а дальше всё сложнее:

```
Уровень 1: 0 XP       Уровень 10: 1800 XP
Уровень 2: 100 XP     Уровень 20: 7200 XP
Уровень 3: 220 XP     Уровень 30: 16200 XP
Уровень 5: 520 XP     Уровень 50: 45000 XP
```

Формула: `XP_для_уровня(n) = 80 * n + 20 * n²`

Это как в Diablo — первые уровни пролетаешь за час, а потом каждый новый уровень всё ценнее.

### 2.3 Сферы жизни (Skill Trees)

5 сфер из оригинала — отличная модель. Улучшения:

| Сфера | Прокачивается через | Пример активностей |
|-------|--------------------|--------------------|
| 🧠 Интеллект | Чтение, курсы, кодинг | Прочитал 30 мин → +15 XP в Интеллект |
| 💼 Дело | Работа, задачи, проекты | Завершил рабочий таск → +20 XP в Дело |
| ⚡ Энергия | Спорт, сон, питание | Тренировка → +25 XP в Энергию |
| 📐 Порядок | Уборка, планирование, финансы | Убрался дома → +15 XP в Порядок |
| 🤝 Связи | Общение, созвоны, мероприятия | Созвонился с другом → +10 XP в Связи |

Каждая сфера имеет **свои уровни** (0–60) с отдельной прогрессией.

### 2.4 Типы квестов

- **Ежедневные** — повторяются каждый день (взвеситься, записать питание, 10000 шагов)
- **Еженедельные** — крупнее (3 тренировки, прочитать главу, генеральная уборка)
- **Сюжетные (эпические)** — долгосрочные цели разбитые на этапы (похудеть на 24 кг = 24 этапа по 1 кг)
- **Побочные** — разовые задачи (купить подарок, сходить к врачу)

### 2.5 Награды и магазин

Монеты зарабатываются за квесты и достижения. Тратятся на «реальные» награды, которые пользователь определяет сам:

- 🍫 Вкусный снек — 5 монет
- 🎮 Час игр без вины — 10 монет
- 🎬 Поход в кино — 30 монет
- 📱 Новый гаджет — 200 монет

Это психологический трюк: ты «заслуживаешь» награду через реальные достижения.

### 2.6 Система достижений (ачивки)

Невидимые цели, которые открываются при достижении вех:

- 🏃 «Марафонец» — 30 тренировок за месяц
- 📚 «Книжный червь» — прочитано 12 книг
- 🔥 «Несгибаемый» — стрик 100 дней
- 💰 «Первый миллион» — накоплено 1000$ к цели
- ⚖️ «Трансформация» — достигнут целевой вес

## 4. Структура базы данных

### Основные таблицы (Supabase / PostgreSQL)

```sql
-- Пользователь
users (
  id UUID PRIMARY KEY,
  username TEXT,
  avatar_url TEXT,
  level INT DEFAULT 1,
  total_xp INT DEFAULT 0,
  coins INT DEFAULT 0,
  created_at TIMESTAMPTZ
)

-- Сферы жизни
spheres (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users,
  name TEXT,           -- 'intellect', 'business', 'energy', 'order', 'social'
  icon TEXT,
  level INT DEFAULT 0,
  current_xp INT DEFAULT 0,
  xp_to_next INT DEFAULT 60
)

-- Активности (навыки)
activities (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users,
  name TEXT,            -- 'Кодинг', 'Сон', 'Видеомонтаж'
  sphere_id UUID REFERENCES spheres,
  level INT DEFAULT 0,
  total_hours FLOAT DEFAULT 0,
  cover_url TEXT,
  is_hidden BOOLEAN DEFAULT false
)

-- Логи активностей
activity_logs (
  id UUID PRIMARY KEY,
  activity_id UUID REFERENCES activities,
  user_id UUID REFERENCES users,
  date DATE,
  duration_minutes INT,
  xp_earned INT,
  notes TEXT
)

-- Квесты (задачи + привычки)
quests (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users,
  title TEXT,
  description TEXT,
  type TEXT,            -- 'daily', 'weekly', 'epic', 'side'
  sphere_id UUID REFERENCES spheres,
  xp_reward INT,
  coin_reward INT DEFAULT 0,
  recurrence TEXT,      -- 'daily', 'weekly', NULL для разовых
  is_active BOOLEAN DEFAULT true
)

-- Завершения квестов
quest_completions (
  id UUID PRIMARY KEY,
  quest_id UUID REFERENCES quests,
  user_id UUID REFERENCES users,
  completed_at TIMESTAMPTZ,
  date DATE
)

-- Цели (долгосрочные)
goals (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users,
  title TEXT,           -- 'На автомобиль'
  target_value FLOAT,   -- 10000
  current_value FLOAT,  -- 2150
  unit TEXT,            -- '$', 'кг', 'шт'
  direction TEXT,       -- 'increase' или 'decrease'
  deadline DATE
)

-- Здоровье (ежедневные метрики)
health_logs (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users,
  date DATE UNIQUE,
  weight FLOAT,
  steps INT,
  calories INT,
  sleep_hours FLOAT,
  notes TEXT
)

-- Питание
nutrition_entries (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users,
  date DATE,
  product_name TEXT,
  grams FLOAT,
  calories FLOAT,
  protein FLOAT,
  fat FLOAT,
  carbs FLOAT
)

-- База продуктов
products (
  id UUID PRIMARY KEY,
  user_id UUID,         -- NULL для глобальных
  name TEXT,
  category TEXT,
  calories_per_100g FLOAT,
  protein_per_100g FLOAT,
  fat_per_100g FLOAT,
  carbs_per_100g FLOAT
)

-- Награды (магазин)
rewards (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users,
  name TEXT,
  icon TEXT,
  cost_coins INT,
  is_favorite BOOLEAN DEFAULT false
)

-- Покупки наград
reward_purchases (
  id UUID PRIMARY KEY,
  reward_id UUID REFERENCES rewards,
  user_id UUID REFERENCES users,
  purchased_at TIMESTAMPTZ
)

-- Достижения
achievements (
  id UUID PRIMARY KEY,
  name TEXT,
  description TEXT,
  icon TEXT,
  condition_type TEXT,  -- 'streak', 'total', 'milestone'
  condition_value INT,
  xp_reward INT,
  coin_reward INT
)

-- Разблокированные достижения
user_achievements (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users,
  achievement_id UUID REFERENCES achievements,
  unlocked_at TIMESTAMPTZ
)

-- Стрики
streaks (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users,
  quest_id UUID REFERENCES quests,
  current_streak INT DEFAULT 0,
  longest_streak INT DEFAULT 0,
  last_completed DATE
)

-- Настройки здоровья
health_settings (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users,
  start_weight FLOAT,
  goal_weight FLOAT,
  calorie_deficit_min INT,
  calorie_deficit_max INT,
  calorie_norm_min INT,
  calorie_norm_max INT,
  daily_steps_goal INT DEFAULT 10000
)
```

## 5. Технологический стек

### Для соло-разработчика — максимум продуктивности, минимум боли:

| Слой | Технология | Почему именно эта |
|------|-----------|-------------------|
| **Frontend** | **Next.js 15 (App Router)** | SSR, роутинг, API routes — всё в одном. Как швейцарский нож |
| **UI** | **Tailwind CSS + shadcn/ui** | Быстрая стилизация без написания CSS с нуля. shadcn — копипаст-компоненты, не зависимость |
| **Анимации** | **Framer Motion** | Простые, но эффектные анимации для геймификации |
| **Графики** | **Recharts** | Для радарных диаграмм, столбчатых графиков, прогресса |
| **База данных** | **Supabase (PostgreSQL)** | Бесплатный тир, встроенная авторизация, realtime, storage для аватаров |
| **Авторизация** | **Supabase Auth** | Google/Email login за 10 минут |
| **Хостинг** | **Vercel** | Деплой Next.js в один клик, бесплатный тир |
| **Состояние** | **Zustand** | Легковесный стейт-менеджер (как Redux, но без боли) |
| **Типизация** | **TypeScript** | Защита от глупых ошибок на этапе написания |

### Почему НЕ Firebase?
Supabase лучше для этого проекта, потому что:
- PostgreSQL вместо NoSQL = сложные запросы для аналитики (итоги за месяц, агрегации)
- Row Level Security = безопасность без лишнего кода
- Бесплатного тира хватит на долго для одного пользователя

## 7. Ключевые алгоритмы

### Начисление XP

```typescript
// lib/xp.ts

export function calculateXP(
  baseXP: number,
  streakDays: number,
  isFocusSphere: boolean,
  completedBefore10am: boolean
): number {
  let multiplier = 1;

  // Стрик-бонус: как комбо в файтинге
  if (streakDays >= 30) multiplier *= 2.0;
  else if (streakDays >= 14) multiplier *= 1.5;
  else if (streakDays >= 7) multiplier *= 1.3;

  // Бонус фокуса
  if (isFocusSphere) multiplier *= 1.2;

  // Утренний бонус
  if (completedBefore10am) multiplier *= 1.1;

  return Math.round(baseXP * multiplier);
}
```

### Формула уровня

```typescript
// lib/levels.ts

// Сколько XP нужно для достижения уровня N
export function xpForLevel(level: number): number {
  return 80 * level + 20 * level * level;
}

// Какой уровень при данном количестве XP
export function levelFromXP(totalXP: number): {
  level: number;
  currentXP: number;
  nextLevelXP: number;
  progress: number;
} {
  let level = 0;
  let xpUsed = 0;

  while (xpForLevel(level + 1) <= totalXP) {
    level++;
    xpUsed = xpForLevel(level);
  }

  const nextXP = xpForLevel(level + 1);
  const currentInLevel = totalXP - xpUsed;
  const neededForNext = nextXP - xpUsed;

  return {
    level,
    currentXP: currentInLevel,
    nextLevelXP: neededForNext,
    progress: currentInLevel / neededForNext,
  };
}
```
